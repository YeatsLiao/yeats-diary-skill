# 夜知日记 - 小红书内容生成 Skill

> 为 Yeats_Liao 打造的小红书跑步书籍笔记生成器

## 功能

- 生成程序员/技术人视角的跑步书籍读后感
- 自然口语化风格，避免AI味
- 输出可直接发布的 Markdown 格式
- 提供多版本标题备选

## 使用方法

### 方式1：直接调用

```
用户：生成《跑步圣经》的笔记
系统：使用本 skill 生成完整笔记 + 标题备选
```

### 方式2：指定风格

```
用户：《Let Your Mind Run》用痛点型标题
系统：生成对应风格的笔记
```

## 文件结构

```
.yeats-diary-xiaohongshu-skill/
├── skill.yaml          # Skill 定义
├── prompt.md           # 核心 Prompt
├── books-database.md   # 跑步书籍数据库
└── README.md           # 本文件
```

## 风格特点

| 维度 | 特点 |
|------|------|
| 视角 | 程序员/技术博主 |
| 语气 | 自然、克制、有余味 |
| 结构 | 个人经历 → 书核 → 迁移 → 收尾 |
| 禁忌 | 少引号、少emoji、不说教 |

## 标题风格

- 悬念型
- 反转型
- 对比型
- 痛点型
- 技术类比型
