# 夜知日记 - 内容生成 Skill

> 为 Yeats_Liao 打造的跑步笔记生成器

## 功能

- 生成程序员/技术人视角的跑步笔记
- 四种创作模式：整本书解读 / 一句话启发 / 思想反常识型 / 跑步体验型
- 七种结构变体：标准体 / 提问体 / 倒叙体 / 书信体 / 清单体 / 极短体 / 日记体
- 自然口语化风格，避免AI味
- 输出可直接发布的 Markdown 格式
- 提供多版本标题备选

## 使用方法

### 方式1：直接调用

```
用户：生成《跑步圣经》的笔记
系统：使用本 skill 生成完整笔记 + 标题备选
```

### 方式2：指定风格

```
用户：《Let Your Mind Run》用痛点型标题
系统：生成对应风格的笔记
```

### 方式3：跑步体验型（高反响）

```
用户：来一篇跑步体验型
系统：不依赖书籍，从真实跑步体验出发生成笔记
```

## 文件结构

```
skill/
├── skill.yaml          # Skill 定义
├── prompt.md           # 核心 Prompt
├── books-database.md   # 跑步书籍数据库
└── README.md           # 本文件
```

## 风格特点

| 维度 | 特点 |
|------|------|
| 视角 | 程序员/技术博主 |
| 语气 | 自然、克制、有余味 |
| 结构 | 七种变体轮换，避免审美疲劳 |
| 禁忌 | 少引号（全文不超过2处）、少emoji、不说教、中文双引号 |
